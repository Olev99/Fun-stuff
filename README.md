# Fun-stuff

- [**Zoomies! Kart Chaos**](zoomies/): a tilt-to-steer kart racer for iPhone, built with three.js. See [zoomies/README.md](zoomies/README.md) for how to play it on your phone.
- [**M4 Lydmotor**](m4-lydmotor/): an engine-sound app for an EV. It synthesises a BMW M4 CSL by default, or an Aston Martin Vanquish S, Aston Martin V12 Vantage S or Ferrari F12berlinetta (picked under Innstillinger), in the browser (gear shifts, overrun burble, tunnel reverb), with an output setting tuned for the i4 M50's Harman Kardon system, from phone GPS and motion sensors, with slope compensation and a status line for screen lock, audio and GPS; it remembers how the phone sits in the holder (reset under Innstillinger). Open it in Safari and add it to the home screen. Rebuild with `python3 m4-lydmotor/src/build.py`; checks: `node m4-lydmotor/src/test.js` (sound) and `node m4-lydmotor/src/sensortest.js` (sensor fusion in headless Chrome).

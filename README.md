# Fun-stuff

- [**Zoomies! Kart Chaos**](zoomies/): a tilt-to-steer kart racer for iPhone, built with three.js. See [zoomies/README.md](zoomies/README.md) for how to play it on your phone.
- [**M4 Lydmotor**](m4-lydmotor/): an engine-sound app for an EV. It synthesises a BMW M4 CSL in the browser (gear shifts, overrun burble, tunnel reverb) from phone GPS and motion sensors. Open it in Safari and add it to the home screen. Rebuild with `python3 m4-lydmotor/src/build.py`.
